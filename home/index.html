How it works

Three moves, in the order the handbook puts them.

The method is not the hard part. Keeping it intact while the product changes is.

1

Structure

Build the system once — next higher element, focus element, next lower level — as a tree, a list or a diagram. Every element, function and failure gets its own identifier you can quote in a review.

2

Analyse

Functions, failure modes, effects and causes, each attached to the level it belongs to. Severity, occurrence and detection in the handbook's column order, with Action Priority computed from the 2019 table.

3

Optimise

Actions with an owner, a type and a target date. Re-rate when they land, and the row carries both assessments — so the improvement is evidence, not an assertion.

Capabilities

Built for the way an FMEA actually gets reviewed.

The chain cannot break

A failure mode is the failure of a function, so Aegix will not let one exist without it. The structure is modelled, not typed into cells — which is what keeps a 400-row worksheet reviewable.

Action Priority, by the book

AP from the AIAG-VDA table decides what gets worked on, not a multiplied RPN the handbook retired in 2019. High AP without an action is a number you can see on one screen.

AI drafts. It never decides.

Generate a structure and candidate failures from your requirements, then review every line before it counts. Turn it off entirely and the tool works exactly the same — the method does not depend on it.

Versions, phases, baselines

A version per design phase and a baseline you can freeze at a release. Work continues on the draft without disturbing what was signed off.

It tells you when it goes stale

Change the structure under a risk and the row says so, instead of quietly pointing at something that moved. Stale FMEAs are found at audits; this one raises its hand.

One view across projects

Risk profile, Action Priority distribution, High AP coverage and overdue actions — per worksheet, per project or across the programme, with the worksheet one click away.

The method

The seven steps, and what Aegix does at each.

If your auditor opens the handbook beside the screen, the two should agree.

Step In Aegix
1 · Planning & preparation Project scope, FMEA type, team and the template that sets the rating scales.
2 · Structure analysis The system tree across three levels, as a tree, a list or a diagram.
3 · Function analysis Functions and requirements attached to the element that performs them.
4 · Failure analysis Effect, mode and cause across the three levels — enforced, not conventional.
5 · Risk analysis Prevention and detection controls, S / O / D, and Action Priority.
6 · Optimisation Actions, owners, target dates, evidence — then revised ratings and a revised AP.
7 · Results documentation Baselines per release, Excel export, and an audit trail on every row.
